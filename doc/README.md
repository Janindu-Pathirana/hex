# hex docs

`hex` is a Go CLI that pulls Colombo Stock Exchange data into a local SQLite store and analyses listed companies.

| File | Contents |
|---|---|
| [features.md](features.md) | Everything hex does today |
| [prediction-research.md](prediction-research.md) | Every candidate signal for accurate prediction, with current status and sources |
| [tasks.md](tasks.md) | Phased task list to get from here to a validated prediction |
| [llm-plan.md](llm-plan.md) | Plan for local Ollama models: extraction backend, `--narrate`, announcement parsing |

Output of `hex` is informational, not investment advice.
